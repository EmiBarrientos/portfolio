# Emiliano Barrientos — Portfolio

Portfolio personal de **Emiliano Barrientos**, desarrollado para presentar proyectos, tecnologías y experiencia en desarrollo de software.

El sitio está construido con **React, TypeScript y Vite**, y se encuentra desplegado en Vercel.

---

## 🌐 Live Demo

**Portfolio:**
https://portfolio-emiliano-barrientos.vercel.app/

## 📋 Descripción

Este proyecto funciona como una presentación personal y profesional de mi trabajo como desarrollador de software.

El portfolio reúne proyectos desarrollados utilizando diferentes tecnologías, con especial foco en **desarrollo backend con Java y Spring Boot**, además de experiencia complementaria en frontend y otras áreas del desarrollo de software.

El objetivo es proporcionar una visión rápida de:

* Proyectos realizados.
* Tecnologías utilizadas.
* Experiencia y conocimientos.
* Perfil como desarrollador.
* Enlaces a los repositorios y proyectos desplegados.

## 🚀 Getting Started

### Requisitos

Para ejecutar el proyecto localmente necesitás:

* Node.js
* npm
* Git

### Clonar el repositorio

```bash
git clone https://github.com/EmiBarrientos/portfolio.git
cd portfolio
```

### Instalar dependencias

```bash
npm install
```

### Ejecutar en desarrollo

```bash
npm run dev
```

La aplicación estará disponible en la URL que indique Vite en la consola, normalmente:

```text
http://localhost:5173
```

## 🎯 Objetivo

El portfolio fue desarrollado como una aplicación web independiente para centralizar mi presentación profesional y mostrar de forma accesible los proyectos que forman parte de mi trayectoria como desarrollador.

Aunque el portfolio utiliza tecnologías frontend modernas, mi principal orientación profesional es el **desarrollo backend con Java y Spring Boot**, utilizando frontend como una capacidad complementaria para construir e integrar aplicaciones completas.

## 📚 Proyectos destacados

Entre los proyectos presentados en el portfolio se encuentran:

### OrderMGMT

Sistema de gestión de pedidos desarrollado utilizando una arquitectura basada en microservicios y tecnologías del ecosistema Spring.

**Tecnologías principales:**

* Java
* Spring Boot
* Spring Cloud
* Spring Security
* Docker
* MySQL
* PostgreSQL
* MongoDB

### Propiedades 360

Aplicación web monolítica para la gestión de propiedades, usuarios, visitas y pagos.

**Tecnologías principales:**

* Java
* Spring Boot
* Spring Security
* JWT
* JPA / Hibernate
* MySQL
* React
* Docker

### MyDoctorApp

Aplicación web para la gestión de turnos y operaciones relacionadas con un sistema médico, desarrollada colaborativamente utilizando metodología Scrum.

**Tecnologías principales:**

* Java
* Spring Boot
* Spring Data JPA
* MySQL
* React
* Tailwind CSS
